## 进度协议

路径：

```text
OUTPUT_DIR/_progress/<progressKey>.json
```

示例：

```json
{
  "key": "123456789",
  "operator": "meta_clean_slice",
  "name": "正文抽取与切片",
  "status": "running",
  "total": 500,
  "processed": 123,
  "succeeded": 118,
  "skipped": 3,
  "failed": 2,
  "review": 5,
  "currentItem": null,
  "startedAt": "2026-11-04T10:00:00+00:00",
  "updatedAt": "2026-11-04T10:00:15+00:00"
}
```

状态取值：`running / completed / failed`。平台读取时依次查找：

```text
WBDZ_OP_RUNTIME_DIR/outputs/_progress/<stage_run_id>.json
WBDZ_OP_RUNTIME_DIR/output/_progress/<stage_run_id>.json
```
