根目录 `operators/`，共享代码在 `operators/_shared_tools/`。

| 目录名 | 中文名 | 产线·环节 | 类型 | 输入 → 输出 |

| `meta_fact_extract` | 新闻事实抽取 | 文本元信息 ② | 文本模型 | 按片抽取来源类型/时间候选/实体 → 合并去重、多值标 conflict |
| `meta_field_fill` | 元信息三组补全 | 文本元信息 ③ | 文本模型 | 标题+正文+事实清单 → 16 字段（4+6+6）逐字段置信度，文档级一次调用 |
| `lay_page_render` | 版面分页渲染 | 复杂版面 ① | 规则 | PDF → 150DPI 页图 + `PageManifest` + 失败页清单 |
| `lay_page_detect` | 逐页版面检测 | 复杂版面 ②③ | 视觉模型 | 页图 → elements(type/bbox/readingOrder/structureTree/双置信度) + 规则分流（低置信/IoU>0.3/越界/重号缺号/空页）+ 汇总 |

| `fml_formula_recognize` | 公式识别与结构化标注 | 公式文本 ②③ | 视觉模型 | 裁切图+页上下文 → 一次调用出 latex/symbols/context/双置信度；LaTeX 语法规则校验，失败走修复 Prompt |
| `img_region_locate` | 图片区域定位与裁切 | 图文融合 ① | CV/规则 | 图片 → `ImageRegion`；失败重试 2 次后跳过（语义待确认 Q1） |
| `img_type_classify` | 图片判型 | 图文融合 ① | 视觉模型 | 图+任务大类 → match/subtype/置信度；大类不一致跳过 |
| `img_struct_describe` | 图文要素与描述生成 | 图文融合 ②③ | 视觉模型 | 按判型选 4 大类 Prompt 之一，一次调用出要素+描述+逐字段置信度；字母/数字回核 |

## 目录结构（单个算子包）

```text
operators/<算子目录名>/
├── inference.py            # 三接口 + /healthz（由 _shared_tools/gen_inference.py 生成，仅常量不同）
├── requirements.txt
├── Dockerfile
├── map.json                # {"<算子目录名>": "<中文名>"}
├── <算子目录名>/
│   ├── operator.py         # 纯算法核心，不 import fastapi
│   ├── configs/config.py   # Prompt 全文、阈值、枚举集中可审计
│   ├── utils/
│   ├── dataset/sample/     # 自造小样本
│   ├── tests/              # 冒烟用例（可离线跑的部分 + 标 api 的联网用例）
│   └── README.md
├── <算子目录名>-算子说明书.md
└── <算子目录名>-测试指令.md
```

共享基建 `operators/_shared_tools/`：

- `llm_config.py`：base_url / api_key / 模型名 / 超时重试（D5）
- `llm_client.py`：OpenAI 兼容调用、JSON mode、重试、并发执行器（4-8）、JSON 提取与越界截断
- `pdf_utils.py`：PyMuPDF 渲染、页清单
- `lineage.py` / `stage_packager.py`：血缘与阶段 zip
- `inference_template.py` / `gen_inference.py`：三接口外壳模板与生成器
- `make_samples/`：各线小样本生成脚本
