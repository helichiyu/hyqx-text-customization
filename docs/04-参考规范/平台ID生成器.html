平台 ID 生成器

按《UI 设计规范手册 · 32.1》生成统一 ID。选择对象类型，点击生成。

选择业务对象类型（决定前缀）
第一层 内部主键 · Snowflake 系统内部，不对外
—
19 位长整型，全局唯一、趋势递增；不暴露在对外 URL / 分享中。
第二层 业务编号 · 前缀+日期+随机 用户可见、可搜索
—
格式：前缀(2–4) + yyMMdd(6) + 6 位安全随机码；去掉 0/O/1/I/L，CSPRNG 生成。
第三层 语义化编码 · 程序对接 稳定不变
—
小写字母+数字+下划线，模块前缀_英文语义；发布后不可更改。

ID 安全铁律

  • 对外禁止用自增 ID（1,2,3…），会暴露总量、可被遍历抓取。
  • 对外 / 分享 ID 必须无规律、不可预测、不可枚举。
  • ID 中不含敏感信息（手机号、身份证、姓名、邮箱、单位名）。
  • 随机数用密码学安全随机（crypto.getRandomValues），不用普通 rand。
  • 新对象类型必须先申请前缀、登记到字典，长度与格式全站统一。
