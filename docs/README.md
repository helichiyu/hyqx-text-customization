## 关键实现要求（跨文档汇总）

1. **四产线链路固定**：元信息 4 算子、版面 2、公式 2、图文 3；线首凭 `uniqueId` 取素材，线内凭 `inputFile` 接续，线末 `isLastOperator=true` 收口阶段 zip。
2. **结果路由**：`skipped` 不进下游；`review` 数据集行保留、继续下游、待人工复核；`failed` 该样本出局；机器码 `code` 供平台建复核单，中文原因供人阅读。
3. **素材准入**：按 `02-研发对齐/素材管理_研发对齐_v2.md` 的窄白名单（元信息 HTML/ZIP、版面与公式 PDF/ZIP、图文 JPG/ZIP）；有效条数 0 判上传失败。
4. **任务状态机**：`draft → pending → processing →（waitreview | quality）→ collected`；无撤销、无暂停；重跑产生新 run，不覆盖旧产物。
5. **数据集口径**：候选条数 = 总数 − 跳过 − C 剔除；发布前来源任务复核单须全部闭环；语义版本 V1.0 直出 / V2.0 复核闭环 / V3.0 起每重跑 +1。
6. **参数与阈值**：参数版本草稿→发布→任务锁定快照；阈值 0.8 待真实样本校准；切片/重叠、IoU 等固定项不开放任务级覆盖。
