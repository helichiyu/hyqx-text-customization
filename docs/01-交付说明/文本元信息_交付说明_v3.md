# 文本元信息 · 交付说明（工作台 / 环节 / 数据集 / 复核 / 参数）
> 一份文档覆盖：状态机与操作、研发版环节清单、执行 Prompt、数据集字段与查看、条件复核、跳过清单、参数配置。  
数据集交付 JSON；查看与复核由前端渲染成【】文本。
>

---

## 一、工作台状态机
### 1.1 状态
| 状态 | 显示 | 含义 |
| --- | --- | --- |
| `draft` | 草稿 | 已建未提交 |
| `pending` | 待启动 | 已提交，等待启动 |
| `processing` | 加工中 | 正在跑环节①②③ |
| `waitreview` | 待复核 | 有问题文档进入复核，未闭环 |
| `quality` | 待归集 | 复核已闭环 |
| `collected` | 已归集 | 已生成数据集 |
| `reject` | 待处理 | 批次不可用或大范围失败 |


### 1.2 流转
```latex
草稿 ──提交──▶ 待启动 ──启动──▶ 加工中
                                  │
                 ┌────────────────┼────────────────┐
            有问题文档        无问题文档        批次失败
                 ▼                ▼                ▼
              待复核           待归集           待处理
                 │ 闭环            │ 归集           │ 修复后重跑
                 └──────▶ 待归集 ──▶ 已归集        └──▶ 加工中
```

+ 任务不支持撤销、暂停；
+ 进度只算环节①②③；环节③结束即 100%，此时可能仍待复核；
+ 有低置信文档但无复核单时，进入详情自动建单并转「待复核」。

## 二、状态与操作关系
| 状态 | 主操作 | 其他操作 | 说明 |
| --- | --- | --- | --- |
| 草稿 | 继续编辑 | 详情 | 不占用素材 |
| 待启动 | 启动 | 详情 | 要求素材已移交 |
| 加工中 | 继续处理 | 详情 | 明细显示空态 |
| 待复核 | 去复核 | 详情 | 打开本任务复核单 |
| 待归集 | 去归集 | 详情 | 复核已闭环 |
| 已归集 | — | 详情 | 只读 |
| 待处理 | 继续处理 | 详情 | 重跑失败环节；批次不可用需换素材 |

## 三、研发版环节清单
### 环节① 文档接入与切片
| # | 动作 | 输出 | 失败处理 |
| --- | --- | --- | --- |
| 1 | 抽取正文并清洗 | 有效文本 | 抽取失败 → 跳过并记录 |
| 2 | 正文校验（空白页 / 导航页 / ≥1 段可读文本） | 通过 / 不通过 | 空白页 / 导航页 / 无有效段落 → 跳过并记录 |
| 3 | 新闻体裁校验（规则粗筛 + 大模型） | `DocRoute` | 置信度 < 0.8 → 进复核；≥0.8 且非新闻 → 跳过 |
| 4 | 长文档按章节切片 | `LongDocSlice` | 边界异常 → 进复核 |


### 新闻体裁判定标准（四条同时满足）
| 条件 | 判定 |
| --- | --- |
| 事件性 | 主体 + 事件 + 时间/地点（5W 至少 3 个） |
| 时效性 | 新近发生或正在发生；时间可识别 |
| 事实性 | 陈述事实为主，非观点/广告/教程/虚构 |
| 公共传播性 | 面向公众，非内部公文/私人通信/产品说明 |


不算新闻：广告软文、产品页、教程科普、评论社论、办事通知、招聘、论文报告、小说、论坛帖、列表页、导航页、图片集。

### 切片规则（固定）
| 项 | 值 |
| --- | --- |
| 单片最大长度 | 2,000 汉字（本项考虑大模型能力） |
| 重叠 | 200 汉字（10%）（本项考虑大模型能力） |
| 切分顺序 | 章节 → 段落 |


### 环节② 事实抽取
| # | 动作 | 输出 | 失败处理 |
| --- | --- | --- | --- |
| 1 | 抽取数据来源类型 | `SourceInfo.sourceType` | 缺失 → 进复核 |
| 2 | 抽取时间线索 | `TimeHint` 候选 | 冲突 → 标记，复核时裁定 |
| 3 | 抽取人物/地点/组织 | `EntityMention`（含位置） | 失败 → 进复核 |


### 环节③ 元信息补全
| # | 动作 | 输出 | 失败处理 |
| --- | --- | --- | --- |
| 1 | 结构化信息补全（4 字段） | `StructuredCompletion` | 缺失/格式非法 → 进复核 |
| 2 | 基础信息补全（6 字段） | `BasicCompletion` | 同上 |
| 3 | 相关信息补全（6 字段） | `RelatedCompletion` | 同上 |
| 4 | 逐字段置信度 | 每字段 0–1 | 输出失败 → 进复核 |


补全方式：切片只用于读，事实合并后**文档级一次补全**；允许“无/不适用”作为合法值。

### 产线内后置（不计入进度）
复核闭环 → 汇总复核结论（总数、成功/跳过/剔除、复核状态），用于归集判断；质量报告在数据集发布后从数据集管理导出。

### 产线外后置
归集（剔除与跳过不计入）→ 数据集 JSON 一文档一行 → 发布前校验复核闭环 → 站内预览 + 质量报告 TXT。

## 四、执行 Prompt（3 个）
| # | Prompt | 输入 | 输出 |
| --- | --- | --- | --- |
| 1 | 体裁判定 | 标题 + 来源 + 正文前 800 字 | is_news、category、四条件、置信度 |
| 2 | 事实抽取 | 标题 + 正文（长文按片） | 来源类型、时间候选、实体、冲突 |
| 3 | 三组补全 | 标题 + 正文 + 事实清单 | 16 字段 + 逐字段置信度 |


### 4.1 体裁判定
```latex
你是新闻体裁判定器。判断给定网页内容是否为“新闻”。

【四条标准，必须同时满足】
1. 事件性：明确主体 + 动作/事件 + 时间或地点（5W 至少 3 个）
2. 时效性：报道新近发生或正在发生的事，时间可识别
3. 事实性：以陈述事实为主，不是观点、广告、教程、虚构
4. 公共传播性：面向公众发布，不是内部公文、私人通信、产品说明

【算新闻】
消息、通讯、特写、专访、发布会报道；事件性政府/企业通报；转载的旧闻（事实报道）。

【不算新闻】
广告/软文/产品页、教程/科普、评论/社论、公文/办事通知、招聘、论文/报告/小说、
论坛帖、列表页、导航页、图片集。

【边界】
政府公告讲“事件发生/处置” → 新闻；讲“办事流程/政策申领” → 非新闻
企业新闻稿讲“签约/发布/人事变动” → 新闻；产品参数/购买页 → 非新闻
深度报道事实为主、少量分析 → 新闻；评论观点为主 → 非新闻

【输出 JSON】
{
  "is_news": true/false,
  "category": "消息/通讯/特写/专访/通报/评论/广告/教程/通知/其他",
  "conditions": {"event": true/false, "timeliness": true/false, "factual": true/false, "public": true/false},
  "confidence": 0.0-0.98,
  "reason": "一句话，指出缺哪条",
  "evidence": ["标题或首段关键句"]
}
```

User：

```latex
标题：{title}
来源：{source}
正文（前 800 字）：{text}
```

规则粗筛已过滤明显非新闻；模型负责边界判定。置信度 < 0.8 → 进复核。

### 4.2 事实抽取
```latex
你是新闻事实抽取器。从正文中抽取：数据来源类型、发布时间候选、人物/地点/组织。

【规则】
1. 只抽文中明确出现的信息，不推断、不补全；
2. 时间保留原文粒度（“6 月 12 日”不补年份；“2021 年 6 月”不精确到日）；
3. 人物/地点/组织必须带原文短句与位置；
4. 同名实体分别列出，不合并；
5. 同一字段多个候选全部保留，并标记 conflict；
6. 抽不到返回空数组，不编造。

【输出 JSON】
{
  "source_type": {"value": "官方媒体/政府网站/企业官网/自媒体/转载/其他", "evidence": "...", "confidence": 0.0-0.98},
  "time_candidates": [{"value": "2021 年 6 月", "granularity": "年/月/日", "evidence": "...", "position": "第 1 段", "confidence": 0.0-0.98}],
  "entities": [{"mention": "张伟", "kind": "person/place/org", "evidence": "...", "position": "第 2 段", "confidence": 0.0-0.98}],
  "conflicts": [{"field": "time", "candidates": ["2021 年 6 月", "2022 年 6 月"], "reason": "首段与末段不一致"}],
  "uncertain": ["..."]
}
```

User：

```latex
标题：{title}
正文：{text}
```

长文按切片分别抽取，合并时按 mention/时间值去重；同一字段多值保留并标记 conflict。冲突不阻断，进入复核。

### 4.3 三组补全
```latex

【输入事实（只作依据，不要改写）】
{facts_json}

【字段定义】

一、结构化信息补全（4）
- 数据来源类型
- 可能的发布时间
- 涉及人物、地点或组织
- 时空变迁信息

二、基础信息补全（6）
- 知识层次：大众常识 / 基础教育 / 学术研究 / 技术应用
- 涉及的知识点列表：至少 3 个核心知识概念
- 主要一级行业
- 行业场景
- 行业类型
- 涉及的角色列表

三、相关信息补全（6）
- 文章风格
- 内容类别
- 价值观：褒/贬/中性
- 历史关联
- 国家关联
- 宗教关联

1. 结构化字段必须以事实清单为依据，不得编造；
2. 基础/相关字段可以推理，但必须给置信度；
3. 确实没有的字段写“无”或“不适用”，不要留空，也不要硬编；
4. 每个字段输出 value 与 confidence（0–0.98）；
5. 知识点少于 3 个时按实际数量输出，并在 uncertain 说明。

【输出 JSON】
{
  "structured": {
    "数据来源类型": {"value": "...", "confidence": 0.0-0.98},
    "可能的发布时间": {"value": "...", "confidence": 0.0-0.98},
```

```latex
标题：{title}
```

### 4.4 调用链
```latex
规则粗筛 → 体裁判定
   ├─ <0.8 → 复核（不论是否新闻）
   ├─ ≥0.8 且非新闻 → 跳过
   └─ ≥0.8 且新闻 → 事实抽取（按片）→ 合并事实 → 三组补全（一次）
```

模型只输出 JSON；数据集交付 JSON；【】文本由前端渲染。

## 七、条件复核说明
按文档复核，复用标准三栏抽屉：

| 区域 | 内容 |
| --- | --- |
| 顶部 | 条件复核 · 任务名；来源任务；触发原因 |
| 指标 | 待复核总数 / 待处理 / 已确认A / 已修正B / 已跳过C |
| 左栏 | 待核条目列表 |
| 右栏 | 左侧原文对照；右侧 16 字段（带置信度与待仲裁标签） |
| 结论 | A 确认无误 / B 直接修正 / C 跳过（不纳入） |


规则：

| 项 | 规则 |
| --- | --- |
| 单位 | 一个文档一条 |
| B 修正 | 可改字段值、实体消歧、时间；保存即生效，不重算质量 |
| C | 该文档不进数据集 |
| 闭环 | 全部条目有结论 → 待归集 |
| 阈值锁定 | 有任一 A/B/C 结论后锁定 |
| 状态回写 | A → 已确认（A）/未修正；B → 已修正（B）/已修正；C → 已剔除（C）/已剔除 |

## 十、质量报告模板（数据集管理导出）
```latex
数据集质量报告
生成时间：{时间}
数据集版本ID：{版本}
质量版本号：{版本}
所属产线：{产线}
来源任务：{taskId} {任务名}
内容条数：{N} 条（已剔除条件复核 C 跳过 {M} 条）
发布状态：已发布（{时间}）
条件复核：未闭环 {N1} 个，已闭环 {N2} 个
```

口径：

| 项 | 说明 |
| --- | --- |
| 内容条数 | 最终进入数据集的条数，不含 C 剔除 |
| 复核处置 | 按复核单统计 A/B/C |
| 跳过 / 失败 | 不进本报告，只在任务详情查看 |

## 十二、已确认与待确认
**已确认**

1. 只校验正文非空（空白页/导航页/无有效段落才算不通过），不卡字数、不做语言校验；
2. 体裁判定：规则粗筛 + 大模型，<0.8 进复核；
3. 16 字段全部进数据集，含价值观/历史/国家/宗教；
4. 复核按文档，A/B/C，C 剔除整篇；
5. 阈值抽取、补全共用 0.80；
6. 切片固定 2,000 字 / 200 字重叠；
7. 补全按文档级一次完成；
8. 模型输出 JSON，视图渲染文本；
9. 不做产线侧去重、不做语言标记；
10. 并发数默认 4–8，与复杂版面一致；
11. 质量报告模板与复杂版面统一；
12. 数据集展示“抽取置信度 + 补全置信度”两列。

**待确认**

无。
