# 复杂版面 · 交付说明（工作台 / 环节 / 数据集 / 复核 / 参数）
> 一份文档覆盖：状态机与操作、研发版环节清单、执行 Prompt、数据集明细字段与查看、条件复核、参数配置。  
对应原型：`prototype_v6.html` 复杂版面产线。

## 一、工作台状态机
### 1.1 状态
| 状态 | 显示 | 含义 |
| --- | --- | --- |
| `draft` | 草稿 | 已建但未提交 |
| `pending` | 待启动 | 已提交，等待启动 |
| `processing` | 加工中 | 正在跑环节①②③ |
| `waitreview` | 待复核 | 有问题页进入复核，尚未闭环 |
| `quality` | 待归集 | 复核已闭环，等待归集 |
| `collected` | 已归集 | 已生成数据集 |
| `reject` | 待处理 | 整份文件不可用或调用大范围失败 |


### 1.2 流转
```latex
草稿 ──提交──▶ 待启动 ──启动──▶ 加工中
                                  │
                 ┌────────────────┼────────────────┐
            有问题页          无问题页          整份失败
                 ▼                ▼                ▼
              待复核           待归集           待处理
                 │ 闭环            │ 归集           │ 修复后重跑
                 └──────▶ 待归集 ──▶ 已归集        └──▶ 加工中
```

说明：

+ 任务不支持撤销、暂停、终止；
+ 进度只统计环节①②③，环节③结束即 100%，此时可能仍在「待复核」；
+ 「待处理」可继续处理，重跑失败环节；文件不可用需换素材重开任务。

## 二、状态与操作关系
| 状态 | 主操作 | 其他操作 | 说明 |
| --- | --- | --- | --- |
| 草稿 | 继续编辑 | 详情 | 不占用素材 |
| 待启动 | 启动 | 详情 | 要求素材已移交 |
| 加工中 | 继续处理（打开任务详情） | 详情 | 进度自动推进 |
| 待处理 | 继续处理（重跑失败环节） | 详情 | 文件不可用需换素材重开任务 |
| 待复核 | 去复核 | 详情 | 打开本任务复核单 |
| 待归集 | 去归集 | 详情 | 复核已闭环 |
| 已归集 | — | 详情 | 数据集只读 |

## 三、研发版环节清单
### 环节① 文档接入与分页
| # | 动作 | 输出 |
| --- | --- | --- |
| 1 | 校验批次归属与可用性 | — |
| 2 | 打开 PDF，校验加密/损坏 | — |
| 3 | 逐页渲染，默认 150 DPI | 页图 |
| 4 | 生成页清单 | `PageManifest`（docId、pageCount、format、pageRange、checksum） |
| 5 | 校验页数 > 0 | — |
| 6 | 页图 + 页号入队 | 交环节② |


失败：整份加密/损坏/0 页 → 待处理；单页渲染失败 → 失败页清单，不送②。

### 环节② 逐页检测
| # | 动作 | 输出 |
| --- | --- | --- |
| 1 | 逐页调用模型（并发 4–8） | 页级元素数组 |
| 2 | 每页输出类型、bbox、页内顺序、框选置信度、判定置信度 | `Element[]` |
| 3 | 生成页面可视化 | 页图 + 框选图层 |
| 4 | 规则分流 | 问题页标记进复核 |
| 5 | 失败处理 | 失败页清单 |


规则：框选 <0.8 或 判定 <0.8、重叠 IoU>0.3、越界、顺序重号/缺号、空页 → 进复核；重试 2 次（最多 3 次）。

### 环节③ 质量校验
| # | 动作 |
| --- | --- |
| 1 | 汇总元素结果 |
| 2 | 汇总失败页清单 |
| 3 | 汇总复核结论 |
| 4 | 问题页加入复核单（只追加，不新建第二张） |


不做自检。

### 产线内后置（不计入进度）
复核闭环 → 汇总复核结论（成功/失败/剔除、复核状态），用于归集判断；质量报告在数据集发布后从数据集管理导出 → 系统性错误人工判定后重跑②。

### 产线外后置
归集（剔除页不计入）→ 数据集一页一行 → 发布前校验复核闭环 → 站内预览 + 质量报告 TXT。

## 四、执行 Prompt（完整）
### 4.1 System Prompt
```latex
你是文档版面分析引擎。输入是一页文档图片，输出该页的版面元素结构。

【任务】
检测页面上所有版面元素，给出：
- 元素类型
- 边界框 bbox
- 页内阅读顺序 readingOrder
- 框选置信度 bboxConf
- 元素判定置信度 typeConf
- 页内结构树 structureTree（父子 / 包含关系）

【元素类型（只能选一个）】
figure   图（照片、示意图、统计图、流程图等）
table    表（含无线表、三线表）
formula  公式（独立成行的公式；行内公式不算）
heading  标题（文章标题、章节标题、小标题）
body     正文段落
header   页眉
footer   页脚
watermark 水印
special  特殊元素（印章、手写批注、页边标记等）
other    其他无法归类的版面块

【坐标】
bbox = [x1, y1, x2, y2]，归一化到 0–1000 的整数，原点在左上角。
要求 x1 < x2，y1 < y2，且都在 0–1000 内。

【阅读顺序 readingOrder】
- 从 1 开始连续编号，覆盖本页所有元素，不重复、不缺号；
- 单栏：自上而下；
- 多栏：先左栏全部，再右栏全部，栏内自上而下；
- 通栏元素（如通栏标题、通栏大图）：按它在页面中的垂直位置插入顺序，跨栏内容不拆开；
- 页眉排在最前，页脚排在最后；
- 水印、特殊元素按其在页面中的位置参与排序；
- 只排本页，不考虑上一页/下一页。

【结构树 structureTree】
- 每个元素给 elementId（e1、e2…，本页唯一）；
- structureTree 只写直接父子关系：[{"id":"e1","children":["e2","e3"]}]；
- 只表达“包含/归属”，不表达阅读顺序；
- 无父子关系时 children 为空数组；
- 不跨页。

【两个置信度】
bboxConf：这个框的边界是否准确（0–1）
typeConf：这个元素的类型判断是否准确（0–1）
- 边界清晰、类型明确：0.90–0.98
- 基本确定但有遮挡/模糊：0.75–0.89
- 拿不准：0.50–0.74
- 不要输出 1.0；不要所有元素给同一个分数

【硬性约束】
1. 只输出一个 JSON 对象，不要输出任何解释、前后缀、Markdown 代码块；
2. 不要提取或输出任何文字内容（不做 OCR）；
3. 不要合并跨页内容，不要推断文档结构；
4. 同一元素只输出一次，不要重复框；
5. 空白页输出空数组 elements: []；
6. 元素数量不要臆造，宁少勿多，漏检比误检代价低。
```

### 4.6 后处理校验
| 校验 | 处理 |
| --- | --- |
| JSON 可解析 | 否则重试 |
| `pageNo` 与请求一致 | 否则重试 |
| bbox 四值、0–1000、x1<x2、y1<y2 | 否则重试 |
| type 在枚举内 | 否则重试 |
| readingOrder 为正整数 | 否则重试 |
| readingOrder 覆盖 1..N 且不重复 | 不阻断，交给规则分流 |

### 4.7 已知局限
1. **置信度不可校准**：模型自评分数只能当“相对高低”，不能当概率；阈值 0.8 需用真实样本校准；
2. **顺序在复杂版面上仍会错**：双栏+通栏混排、图表穿插是主要错误源，需要人工复核兜底；
3. **表格与公式边界**：模型常把表格标题一起框进表、把公式编号框在外，需在复核里修；
4. **页眉页脚**：有的版式页眉含章节名，模型可能判成 heading，靠复核纠正；
5. **空白页**：模型可能输出噪声框，规则里“空页进复核”可兜住。

## 五、数据集明细字段说明
一页一行，行来自 `page.status=detected`（失败页不出现）；C 页保留一行并标「已剔除」。

| 字段 | 类型 | 来源 | 说明 |
| --- | --- | --- | --- |
| 页面编号 | string | `taskId-#页码` | 显示用 |
| 元素数 | int | 该页 `elements.length` | — |
| 结构树 | JSON | 页内层级关系 | 父子/包含关系 |
| 页内阅读顺序 | array | `elements` 按 readingOrder 排序 | 1 起连续编号 |
| 框选置信度 | 0–1 | 页内 `bboxConf` 最小值 | 低于阈值标红 |
| 判定置信度 | 0–1 | 页内 `typeConf` 最小值 | 低于阈值标红 |
| 低置信项 | int | 两个分数中低于阈值的个数（0–2） | — |
| 低置信原因 | string | 规则命中项：框选偏低 / 判定偏低 / 重叠 / 越界 / 顺序冲突 / 空页 | 多条用“；”连接 |
| 复核状态 | enum | 未进入复核 / 待复核 / 已确认A / 已修正B / 已剔除C | C 页保留并标注 |
| 修正状态 | enum | 未修正 / 已修正 / 已剔除；未进入复核显示「—」 | 来自复核结果 |
| 操作 | — | 查看 | 打开页面可视化抽屉 |

## 七、条件复核说明
| 项 | 规则 |
| --- | --- |
| 单据 | 一个任务一张，条目 = 问题页 |
| 入口 | 工作台「去复核」→ 任务详情 →「条件复核」 |
| 结论 | A 确认保留 / B 修正后保留 / C 整页剔除 |
| B 能力 | 拖框、改类型、改顺序、补框、删框；保存立即生效 |
| B 影响 | 不重新计算质量；`revisionStatus=edited` |
| C 影响 | 该页不计入数据集；`revisionStatus=removed` |
| 闭环 | 全部条目有结论 → 任务转「待归集」 |
| 阈值锁定 | 已有任一 A/B/C 结论后，低置信阈值不可再改 |
| 重跑 | 系统性错误重跑②时，旧复核单作废（void） |
| 状态回写 | A → 已确认（A）/未修正；B → 已修正（B）/已修正；C → 已剔除（C）/已剔除 |

## 八、参数配置说明
### 8.1 现有机制（本产线不配置“版面检测算子”）
参数页采用「草稿 → 发布版本 → 任务快照」：任务启动时固化参数版本，后续改参数不影响已启动任务。

### 8.2 参数清单
| 参数 | 默认 | 生效范围 | 说明 |
| --- | --- | --- | --- |
| 渲染 DPI | 150 | 全局可配（任务快照） | 150–200 |
| 并发数 | 4–8 | 全局可配 | 单任务逐页调用并发 |
| 低置信阈值 | 0.8 | 任务级可配 | 两个分数共用，在数据集明细调整 |
| 单页超时 | 60 秒 | 固定 | 不可配 |
| 重试次数 | 2（最多 3 次） | 固定 | 不可配 |
| 重叠 IoU | 0.3 | 固定 | 不可配 |


### 8.3 约束
+ 全局参数改动只影响新启动任务；
+ 任务级阈值改动后立即重算复核范围；
+ 已有结论的复核单锁定阈值；
+ 参数版本随任务快照展示，可在任务详情查看。

## 十二、已确认与待确认
**已确认**

1. 只做单页内检测与页内顺序，不做跨页；
2. 不做 OCR、不存正文；
3. 逐页调用，失败页跳过并记录；
4. 两个置信度共用 0.8，任务级可调；
5. 复核按页，A/B/C，C 整页剔除；
6. 环节③只汇总，不自检；
7. 进度只算①②③，结束即 100%，可能仍待复核；
8. 参数只配渲染 DPI、并发数，阈值任务级，其余固定；
9. 质量报告模板与图文融合 / 文本元信息统一。

**待确认**

无。
