# 素材管理 · 研发对齐（v2 修订）
> 修订说明：补充「上传失败」状态、编辑与删除规则、变更记录、上传上限；校验结果统一为“剔除 / 通过”，去掉“阻断”表述。
>

## 一、范围
素材管理是四条产线共用的公共模块，负责：

1. 素材批次上传（单文件 / 多文件 / ZIP）
2. 素材准入校验（格式、大小、分辨率、去重、编码等）
3. 素材状态流转（未校验 → 已校验 → 已移交 → 已关联；校验不通过 → 上传失败）
4. 与任务的关联（任务创建即视为已关联）

产线内部的环节校验（如图文大类一致性、元信息新闻体裁、版面区域定位）不属于素材管理，见第五节「两层准入」。

---

## 二、支持文件类型
### 2.1 白名单
| 产线 | 上传弹窗展示 | 实际允许扩展名 |
| --- | --- | --- |
| 公式文本 | PDF / ZIP | `.pdf .zip` |
| 复杂版面 | PDF / ZIP | `.pdf .zip` |
| 图文融合 | JPG / ZIP | `.jpg .jpeg .zip` |
| 文本元信息 | HTML / ZIP | `.html .zip` |


### 2.2 规则说明
+ 白名单**按产线固定维护**，不在参数配置页开放修改；
+ 前端文件选择器通过 `accept` 做第一道过滤，服务端按同一白名单复校验；
+ ZIP 只是容器：解压后按产线白名单逐个校验，**不符合白名单的文件按“剔除 + 计数”处理，不整批失败**；上传弹窗注明“ZIP 内不支持的文件会被跳过”；
+ ZIP 损坏 / 加密 / 嵌套 ZIP → 整批拒绝。

## 三、状态机
### 3.1 流线
```latex
未校验 ──准入校验通过(仍有有效条目)──▶ 已校验 ──移交──▶ 已移交 ──任务创建──▶ 已关联

未校验 ──校验后有效条数为 0──▶ 上传失败 ──删除──▶ 结束（重新上传）
```

### 3.2 状态与可用操作
| 状态 | 查看 | 准入校验 | 移交 | 编辑基本信息 | 删除 |
| --- | --- | --- | --- | --- | --- |
| 上传失败 | ✅ | ❌ | ❌ | ❌ | ✅ |
| 未校验 | ✅ | ✅ | ❌ | ✅ | ✅ |
| 已校验 | ✅ | ❌ | ✅ | ✅ | ✅ |
| 已移交 | ✅ | ❌ | ❌ | ✅ | ❌ |
| 已关联 | ✅ | ❌ | ❌ | ✅ | ❌ |


### 3.3 关键规则
1. **批次内文件不可编辑**：校验通过后不能增删改批次内的文件；只能改基本信息（批次名称、所属产线）。
2. **校验失败 = 上传失败**：校验结果为“剔除”，当剔除后有效条数为 0 时，批次状态为「上传失败」；上传失败只能**删除后重新上传**，不支持原地重试。
3. **门禁**：创建正式任务（待启动及以上；草稿不校验）与启动任务，都要求批次已**移交**；未移交不能建任务，也不能启动任务。
4. **已关联的判定**：只要批次被任一非草稿任务引用，即视为已关联——包括**待启动、加工中、待处理**的任务。
5. **删除限制**：仅**未校验、已校验、上传失败**可删除；**已移交、已关联不可删除**；被任务引用的批次一律不可删除。
6. **编辑限制**：可改**批次名称与所属产线**；改产线需满足：① 未被任务引用；② 批次格式符合目标产线白名单。改基本信息**不需要重新准入校验**。
7. **变更记录**：名称、所属产线的每次修改都自动记录（时间、操作人、变更项、改前、改后）；记录**永久保留**，**批次删除时一并删除**。
8. **任务不支持撤销**（产品已删除撤销功能）；已关联状态不因任务结束、删除而回退。
9. 批次被多个任务引用时，删除门禁按“任一引用即锁定”执行。

## 四、准入校验规则
### 4.1 通用检查项（四条线都查）
| 检查项 | 规则 | 级别 | 不通过结果 |
| --- | --- | --- | --- |
| 格式 | 命中本产线白名单 | 必查（自动剔除，不阻断） | 剔除，计入剔除情况 |
| 单文件大小 | ≤ 50 MB（可配） | 必查（自动剔除，不阻断） | 剔除，计入剔除情况 |
| 批次名称唯一 | 不与同产线已有批次重名（含上传失败批次） | 必查 | 上传失败 |
| 重复文件 | 同批次内哈希一致即剔除，记录条数 | 必查（自动剔除，不阻断） | 剔除，计入剔除情况 |


> 没有“批次非空”检查项；批次级失败统一由“剔除后有效条数为 0”触发。
>

### 4.2 分产线检查项
**公式文本**

| 检查项 | 规则 | 级别 | 不通过结果 |
| --- | --- | --- | --- |
| PDF 可渲染 | 不加密、不损坏、逐页可转图 | 必查（自动剔除，不阻断） | 剔除 |
| 页数 | > 0 | 必查 | 剔除后为 0 则上传失败 |


**复杂版面**

| 检查项 | 规则 | 级别 | 不通过结果 |
| --- | --- | --- | --- |
| PDF 加密 / 损坏 | 无加密、可解析 | 必查（自动剔除，不阻断） | 剔除 |
| 页数 | > 0 | 必查 | 剔除后为 0 则上传失败 |


**图文融合**

| 检查项 | 规则 | 级别 | 不通过结果 |
| --- | --- | --- | --- |
| 图片可解码 | 能正常解码 | 必查（自动剔除，不阻断） | 剔除 |
| 分辨率 | ≥ 600×600 | 必查（自动剔除，不阻断） | 剔除 |
| 单张大小 | ≤ 50 MB | 必查（自动剔除，不阻断） | 剔除 |


**文本元信息**

| 检查项 | 规则 | 级别 | 不通过结果 |
| --- | --- | --- | --- |
| 编码可识别 | UTF-8 / GBK / GB18030 | 必查（自动剔除，不阻断） | 剔除 |
| 正文非空（粗检） | 去标签后可读字符 ≥ 20 | 必查（自动剔除，不阻断） | 剔除 |


### 4.3 结果定义
| 结果 | 含义 | 后续 |
| --- | --- | --- |
| 通过 | 该文件可用 | 计入素材数量 |
| 已剔除 | 该文件不可用 | 不计入数量，原因逐类记录，展示在「剔除情况」 |
| 上传失败 | 剔除后有效条数为 0 | 批次不可用，只能删除后重传 |

## 五、两层准入校验
### 5.1 分层职责
| 层 | 时机 | 负责内容 |
| --- | --- | --- |
| **素材侧** | 上传时 + 「准入校验」动作 | 格式、大小、有效条数、名称唯一、去重、编码、分辨率等 |
| **产线侧** | 创建任务时、启动任务时、环节① | 批次归属与可用性、大类一致性、体裁、区域定位 |


### 5.2 产线侧检查项
| 检查 | 产线 | 时机 | 不通过处理 |
| --- | --- | --- | --- |
| 大类一致性 | 图文融合 | 环节①（图片接入与分类） | 不一致 → **跳过该图** |
| 新闻体裁 | 文本元信息 | 环节①（文档接入与切片） | 非新闻 → **跳过该文档** |
| 区域定位 / 裁切 | 图文融合 | 环节① | 失败 → 任务待处理（可重跑失败环节） |


### 5.3 边界原则
+ 素材侧只回答“这批文件能不能用”，不回答“内容对不对”；
+ 产线侧只回答“这批素材配不配这个任务”，不重复做格式/大小校验；
+ 两层都通过，任务才允许进入加工。

## 六、规则配置
### 6.1 可配置项
| 配置项 | 默认值 | 位置 | 生效范围 |
| --- | --- | --- | --- |
| 单文件大小上限 | 50 MB | 参数配置 → 素材准入规则 | 全部产线 |
| 图片最小分辨率 | 600 × 600 | 参数配置 → 素材准入规则 | 图文融合 |
| 允许格式 | 按产线固定 | 不开放配置 | — |


### 6.2 生效规则
+ 修改后**仅影响后续上传与准入校验**，不改动已入库批次；
+ 配置带版本号，批次记录校验时所用版本，便于追溯。

### 6.3 上传上限（临时值）
| 项 | 上限 |
| --- | --- |
| 单次上传文件数 | 200 个 |
| 单批次素材条数（页） | 5,000 |
| 单个 ZIP 包 | 2 GB |
| ZIP 解压后总量 | 10 GB |


> 数值为占位值，后续按大模型处理能力调整。
>

## 八、素材数量判定标准
### 8.1 计数口径
| 场景 | 计数方式 |
| --- | --- |
| ZIP 上传 | 按解压后可识别的素材文件 / 页数计 |
| PDF（复杂版面） | **按页计**：入库时展开页数，1 页 = 1 条素材 |
| PDF（公式文本） | **按页计**：入库时展开页数；产线再裁出公式图片，数据集按公式图片计 |
| 批次数量 | 批次内有效素材数量之和（剔除后） |
| 去重 | 同批次内哈希一致的文件只计 1 个，并记录剔除条数 |


### 8.2 单位
| 产线 | 任务范围单位 | 说明 |
| --- | --- | --- |
| 公式文本 | 素材：页；数据集：公式图片 | 素材库按 PDF 页数计；产线裁出公式图片后，数据集按公式图片计 |
| 复杂版面 | 页 | 批次数量 = PDF 页数；入库即展开 |
| 图文融合 | 张 | 一图一张 |
| 文本元信息 | 条 | 一个文档一条 |


### 8.3 上限
见 6.3，上限为临时值，按大模型能力调整。

## 九、变更记录
| 项 | 规则 |
| --- | --- |
| 记录范围 | 仅基本信息：批次名称、所属产线 |
| 记录内容 | 时间、操作人、变更项、变更前、变更后 |
| 展示位置 | 素材批次详情弹窗 → 「变更记录」折叠区（最近 5 条） |
| 保留规则 | 永久保留，不做定期清理；批次删除时一并删除，不支持跨批次追溯 |
| 可编辑性 | 记录只读，不可修改、不可删除 |

## 十、已确认
1. 上传失败后的恢复方式统一为“删除后重新上传”；
2. 上限数值需要随大模型能力调整；
3. 任务删除功能是否上线（当前原型无入口；已关联素材不因任务删除回退）。
