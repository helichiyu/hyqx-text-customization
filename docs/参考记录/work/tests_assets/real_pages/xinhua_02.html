萌娃看发射 追火箭的别样暑假

2022-07-24 16:57:04 来源： 新华网

 

　　北京时间2022年7月24日14时22分，搭载问天实验舱的长征五号B遥三运载火箭，在我国文昌航天发射场准时点火发射，约495秒后，问天实验舱与火箭成功分离并进入预定轨道，发射取得圆满成功。正值暑期，全国各地众多萌娃在家长、老师的带领下，齐聚文昌，一同见证火箭发射升空的震撼场面。对于此次问天实验舱发射，萌娃也有着自己的期待和不一样的仪式感。一起通过镜头来感受一下这些孩子们不一样的暑假吧！
