## 4. 四线真实 smoke（当前阻塞）

入口：`docs/pst-execution-run-smoke-runbook.md`（PST 仓库）。

自动化测试：`PstProdExecutionSmokeTest`，由环境变量控制：

| 变量 | 必填 | 说明 |
| --- | --- | --- |
| PST_SMOKE_BASE_URL | 是 | 含 `/hs-api` 的 PST API 前缀；缺失时测试跳过 |
| PST_SMOKE_UAP_COOKIE / PST_SMOKE_AUTHORIZATION | 二选一 | 会话凭据，仅环境读取 |
| PST_SMOKE_{SFT,RLHF,REASONING,EVAL}_DATASET_ID | 是 | 每线 AUTHORIZED 数据集 ID |
| PST_SMOKE_{SFT,RLHF,REASONING,EVAL}_TEMPLATE_ID | 是 | 每线已发布模板 ID |
| PST_SMOKE_CRAFT_STEP | 否 | 默认 0 |
| PST_SMOKE_TIMEOUT_SECONDS | 否 | 默认 1800 |
| PST_SMOKE_CLEANUP | 否 | 默认 true，仅清理本次创建的任务 |

通过标准：
1. 四线各至少一次 STARTED→DONE；
2. exec_log 含逐算子记录与 `__DONE__`；
3. operator_run 有 SUCCESS 记录，costMs/rows 有值；
4. execution/asset 返回 ossId 与 lineageRef，下载可打开；
5. 无 401/403。

当前阻塞（2026-11-11 连续三轮确认）：

- 测试环境 UAP 会话与数据集/模板 ID 未提供。
