# 环境部署与算子池配置

## 1. 本地开发端口约定（仅本地，不得提交）

| 服务 | 端口 | 说明 |
| --- | --- | --- |
| PRE 后端 | 8080 | 启动参数附加 `--spring.profiles.active=local` 时走本地绕权配置 |
| PST 后端 | 8081 | 启动参数 `--server.port=8081`，与 PRE 并行 |
| Web 前端 | 9848 | Vite dev server，代理目标按需要指向 8080 或 8081 |

这些端口覆盖只存在于本地运行参数/IDE 配置中，仓库默认配置保持 8080。禁止把 8081 端口改动、本地绕权类、Jasypt 兼容配置提交到仓库。

## 3. 鉴权（X-Token）

四个后训练池与三个行业池共用 X-Token。真实值不得写入交接文档，应由负责人通过密码管理器、部署 Secret 或安全审批渠道单独移交。

```text
X-Token: <通过安全渠道获取>
```

- 历史上该值曾按负责人要求直写 PST `application.yml`，因此**已进入 Git 历史**。
- 安全要求：上生产前必须由算法组按池轮换，轮换后通过 Secret/环境变量注入，不再写入代码或文档。
- 请求头作用于全部出站请求：health / uploadFile / predict / downloadFile / removeFile（RLHF 为 health / predict / removeFile）。
- 401/403 在 PST 客户端中映射为独立鉴权异常（Auth），不与通用传输错误混淆。

## 5. PST 关键环境变量

| 变量 | 用途 | 备注 |
| --- | --- | --- |
| `PRE_SERVICE_URL` | PRE Feign 基地址 | 必须包含 `/hs-api/pre` 前缀 |
| `PRE_UAP_COOKIE` / `PRE_AUTHORIZATION` | PRE 只读 smoke 会话 | 二选一，禁止落盘或提交 |
| `OSS_SERVICE_URL` | OSS 上传下载地址 | 为空时上传下载稳定返回 UNAVAILABLE，不阻塞启动 |
| `SFT_OPERATOR_BASE_URL` 等 | 四线算子池地址 | 当前按负责人要求直写，环境变量仅作覆盖能力 |
| `PST_SMOKE_*` | 四线真实 smoke | 详见测试文档与 runbook |

## 6. K8s / 部署要求

1. PST Pod 必须能解析并访问 `oppretrainsftpool:17054`、`oppretrainrlpool:17055`、`oppretraincotpool:17056`、`oppretrainevalpool:17057`（NetworkPolicy 放行）。
2. 鉴权 token 建议用 Secret + `envFrom` 注入。
3. CoT / EVAL 必须部署算法组确认的修复版镜像，tag/commit 需由部署侧记录。
4. IND 三个池同理：`opsporturbanlowaltitudetrafficpool:17060`、`opfinanceteachfamilycommunicationpool:17061`、`opoceanmedicinetreatmentsecuritypool:17062`。
5. 本地工作站无法解析这些集群内 DNS，真实联调必须在集群内由 PST Pod 发起。

## 7. 数据库准备

1. 准备独立 MySQL 8 或 PostgreSQL 14 实例，禁止指向共享 `idg_db`。
2. 首次部署执行 PST Liquibase 全量 changeSet（当前约 45 个，后续以仓库为准）。
3. 二轮执行应显示 `Run: 0 / Previously run: N`，否则视为幂等缺陷。
4. 若复用 PRE 共享表，确认表结构版本一致；PST 独立 H2 测试环境下 033 changeSet 会以 MARK_RAN 跳过。
