## 5. 接手第一周建议

1. 拉取 PST 新框架代码，JDK 21 + Maven 3.9.16 跑通聚合构建。
2. 通读 PST 仓库 docs 目录下：`pst-execution-run-orchestration.md`、`pst-execution-run-smoke-runbook.md`、`pst-execution-run-source-traceability.md`、`pst-known-issues.md`。
3. 拉取 Web 前端，用 Corepack 固定 pnpm 10.17.1（仓库声明版本），跑通构建。
4. 找运维开通 K8s 访问，确认四个算子池 DNS/网络；找算法组要 CoT/EVAL 镜像 tag。
5. 环境齐备后按 runbook 跑四线 smoke，产出第一份真实联调证据。
