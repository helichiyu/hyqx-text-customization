## 3. 分线明细

### 3.1 文本元信息线（样本池）

输入 `samples_pool/meta`：`news_001.html`、`news_002.html`、`nonnews_navlist.html`、`nonnews_product.html`、`nonnews_tutorial.html`。

| 环节 | summary | 说明 |
| --- | --- | --- |
| `meta_clean_slice` | `total=5, kept=4, skipped=1` | 导航页未通过正文闸门，`skipped` |
| `meta_genre_judge` | `total=4, news=2, review=0, skipped=2` | 产品页、教程页判为非新闻，`skipped` |
| `meta_fact_extract` | `total=2, extracted=2, review=1, failed=0` | `news_001` 因 `candidate_conflict`（time）进复核 |
| `meta_field_fill` | `total=2, filled=2, review=1, failed=0` | `news_002` 因 `low_confidence`（0.75 < 0.8）进复核 |
| 阶段 zip | 数据集 2 行 | `news_001`：0.85，未进入复核；`news_002`：0.75，待复核 |

链路脚本：`.scratch/chain_meta.py`；产物：`.scratch/chain_meta_runtime/output/`。

### 3.2 文本元信息线（AISHELL-1 转写文本）

数据源：`data/speech_asr_aishell1_trainsets_500条`（500 条 wav + 转写 CSV）。

- 音频不能作为本项目任何算子的输入；转写文本只能喂 meta 线。
- 逐句流转写：500 条中 65 条达到 `meta_clean_slice` 的 20 字下限，435 条 `skipped`。
- 同说话人相邻 20 句重建为 26 篇新闻段落（约 280–350 字），26 篇全部通过清洗切片。
- `meta_genre_judge`：新闻 3 篇、复核 7 篇、非新闻跳过 16 篇。
- `meta_fact_extract`：抽取 3 篇，3 篇均进复核（2 篇时间候选冲突 + 置信度不足）。
- `meta_field_fill`：补全 3 篇，3 篇均进复核（置信度 0.0–0.7）。
- 明细报告：`D:\opMeta_asr\meta_chain_report.md`；脚本：`.scratch/prep_meta_asr.py`、`.scratch/chain_meta_asr.py`。

> 该批产出中的置信度与语义结论均为模型自评，未经人工判定；用于验证链路与路由，不作为质量验收依据。

### 3.4 公式文本线

输入 `samples_pool/fml/formula_sample.pdf`（2 页）。

| 环节 | summary | 说明 |
| --- | --- | --- |
| `fml_formula_locate` | `total=1, located=1, failed=0, instances=3` | 3 个独立公式，其中 1 个带编号 `(2-3)` |
| `fml_formula_recognize` | `docs=1, instances=3, recognized=3, review=1, failed=0` | `E = mc^2` 语义置信 0.5 < 0.8 → `review` |
| 阶段 zip | 3 行（一公式一行） | `trace.jsonl` 正常生成；数据集不含 `bbox/pageNo` |

其余两个公式：`\frac{a}{b} + \sqrt{x} = \sum_{i=1}^{n} c_i`（双置信 0.95/0.92）、`f(x) = x^2 + 2x + 1 \\ = (x + 1)^2`（0.95/0.85）。

脚本：`.scratch/chain_fml.py`；产物：`.scratch/chain_fml_runtime/output/`。

### 3.5 图文融合线

输入 `samples_pool/img`：`chart_001.jpg`、`geometry_001.jpg`、`lowres_001.jpg`、`schematic_001.jpg`、`table_001.jpg`。按 4 个任务大类各跑一遍。

| 任务大类 | `img_region_locate` | `img_type_classify` | `img_struct_describe` |
| --- | --- | --- | --- |
| 几何 | 5/5 定位裁切 | 匹配 2（geometry_001、lowres_001），跳过 3 | 2 行，0 复核 |
| 统计 | 5/5 | 匹配 1（chart_001），跳过 4 | 1 行，1 复核 |
| 表格 | 5/5 | 匹配 1（table_001），跳过 4 | 1 行，0 复核 |

- 跳过项均带 `code=category_mismatch`，中文原因含“任务=统计，实际=表格”一类对照，未进入下游。
- 统计图 `chart_001` 的描述进入复核（`review`），数据集行保留。

## 4. 路由语义核对

| 路由 | 实测证据 |
| --- | --- |
| `skipped` 不进下游 | 导航页未出现在 `meta_genre_judge` 的输入；非新闻页未进入事实抽取；大类不匹配图片未进入描述；435 条短转写未进入清洗产物 |
| `review` 数据集保留并继续下游 | 空白页仍在版面数据集第 3 行；`news_002`、`E=mc^2`、`chart_001` 均留在各自数据集中并标记待复核 |
| `failed` 该样本出局 | 加密 PDF 未产出页面，记录在 `failed` 列表并带机器码；下游页数为 3 而非 5 |

## 5. 实测观察（非缺陷）

1. `lowres_001.jpg`（320×240）被正常受理，裁切 245×164，归类为“平面几何图”。`img_region_locate` 当前只有 `MIN_CROP_SIZE=32` 的最小裁切边长，没有整图分辨率门槛；若业务要求低清图拒收，需要新增规则，现有实现不会自动拦截。
2. 逐句 AISHELL 转写大量低于 20 字下限，65/500 通过；直接用语音转写做 meta 素材时，需先按段落聚合，否则跳过率约 87%。
3. 版面检测对扫描页的视觉调用较慢（3 页约 100 秒，含一次 60 秒超时重试）；批量任务建议关注超时配置与并发。
4. 公式与图片的置信度同样是模型自评，未经人工判定。
